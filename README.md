## 🚀 Featured Projects

### 1. 🎵 [Real-Time Spotify Music Analytics Pipeline](https://github.com/Chandu-Sanchi/spotify_project) *(Jan 2026 – Mar 2026)*
* **Overview:** An end-to-end streaming data pipeline ingesting simulated Spotify user playback events into object storage and transforming data in Snowflake for real-time reporting.
* **Architecture:**
  - **Streaming:** Python event producers streaming to an **Apache Kafka** broker topic.
  - **Storage:** Raw landing in **MinIO** S3-compatible object storage.
  - **Transformation & Testing:** Modular dimensional models and automated testing suites built using **dbt** on **Snowflake**.
  - **Orchestration:** Scheduled and orchestrated DAGs using **Apache Airflow** packaged in **Docker** containers.
  - **Analytics:** Executive **Power BI** dashboards visualizing song popularity, top artists, regional listenership, and device metrics.
* **Tech Stack:** `Python`, `Apache Kafka`, `Snowflake`, `dbt`, `MinIO`, `Apache Airflow`, `Docker`, `Power BI`, `SQL`

## ⚡ Getting Started Locally

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation & Run

1. Clone the repository:
   ```bash
   git clone https://github.com/chandu-1234567-lab/Protfolio.git
   cd Protfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
